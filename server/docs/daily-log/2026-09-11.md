2. Learned about `Zod` methods and the different kinds, such as `Base Types` and `Refinements`. Base types start the chain, and refinements continue the chain (as a quick summary). Here's a little cheat sheet I had gemini make me lol:

```markdown
## 1. Base Types (Start the chain)

_Standalone constructors—cannot be chained onto other types._

- `z.string()` / `z.number()` / `z.boolean()`
- `z.enum(["A", "B"])` / `z.nativeEnum(TypeScriptEnum)`
- `z.object({})` / `z.array()`

## 2. Type Refinements (Chain onto specific types)

_Methods that only exist on matching Base Types._

- **Strings:** `.trim()`, `.min()`, `.max()`, `.email()`, `.toLowerCase()`
- **Numbers:** `.int()`, `.positive()`, `.negative()`, `.gte()`

## 3. Universal Modifiers (Chain onto ANY type)

_Global methods used to modify the final output or metadata._

- `.optional()` (adds `| undefined`)
- `.nullable()` (adds `| null`)
- `.default(value)` (fallbacks if input is missing)
- `.describe("text")` (adds metadata)
```
