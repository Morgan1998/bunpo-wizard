2. Here's how we could write our RBAC middleware:

```typescript
export const authorize = (...allowedRoles: string[]) => {
  return (req: Request, res: Response, next: NextFunction) => {
    if (!allowedRoles.includes(req.user.role)) {
      return next(
        new AppError(
          'You do not have permission to perform this action',
          403,
          'FORBIDDEN',
        ),
      );
    }
    next();
  };
};
```

So the idea here is that since express only auto plugs in `req`, `res`, and `next`, it'd be confused if we passed in our own arg, to a regular function, such as allowedRoles. So that's where the higher order functions helps out. It basically allows us to configure the middleware function we wrote before Express uses it. We call it right away inside of the route handler which returns the inner anonymous function (our middleware function) and leaves behind the middleware function sitting there ready to be called when a client hits the endpoint that matches that route handler. Boom!
