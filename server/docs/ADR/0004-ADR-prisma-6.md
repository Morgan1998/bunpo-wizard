## Prisma 6 instead of Prisma 7 or 8

We're going with Prisma 6! Why? Prisma 8 is super new and there's very little examples out there for a little junior dev like me. Also, Prisma 6 still uses some lower level stuff like rust to make configuration a little easier. Prisma 7 pulled some of that stuff out. Also, the Odin Project recommends Prisma 6, and I'm an Odinite! :D
